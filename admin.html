❓ Admin Panel — How to Use

📅 रोज़ का काम (Daily Routine)

  1. सुबह admin panel खोलें → "नई Entry Add करें" tab पर जाएं
  2. आज की तारीख, समय, event name, और location fill करें
  3. "Entry Save करें" बटन दबाएं
  4. JSON popup आएगा — उसे copy करें
  5. data/schedule.json file खोलें (Notepad से) और पूरा content replace करें
  6. Save करें — website पर automatically update हो जाएगा!

🔐 Password बदलना

js/main.js file खोलें और line पर const ADMIN_PASSWORD = 'vasudev2026'; में password बदलें।

📰 News Add करना

data/news.json file में नई entry add करें। Format:

{"id":"6","date":"2026-09-09","source":"Newspaper","headline":"खबर का शीर्षक","summary":"विवरण…","url":"https://link-to-article.com"}

📸 Photos Add करना

images/gallery/ folder में photo डालें और gallery.html में उस photo का src update करें।

💡 Production में Deploy करने के बाद:
एक PHP/Node.js backend बनाएं जो directly schedule.json file write कर सके — इससे Copy-Paste step की ज़रूरत नहीं रहेगी। Developer से संपर्क करें।
