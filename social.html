📋 Instagram Feed Setup Guide

1️⃣

Account Convert करें

Instagram settings में जाएं → Account → Professional Account → Creator/Business। दोनों accounts के लिए करें।

2️⃣

Elfsight पर जाएं

elfsight.com पर account बनाएं → Instagram Feed widget चुनें → Account connect करें → Embed code copy करें।

3️⃣

Code Paste करें

इस page (social.html) में "social-embed-box" वाले div को Elfsight का embed code से replace कर दें।

Alternative: Graph API के लिए developer से संपर्क करें। यह completely free है लेकिन setup में 1-2 दिन लगते हैं।
